# Desenvolvedora Full Stack | Inteligência Artificial e Análise Preditiva

Sou desenvolvedora Full Stack, com conhecimentos em desenvolvimento de aplicações web, arquitetura Back-End, construção de APIs REST, integração de sistemas e gerenciamento de bancos de dados relacionais.

No desenvolvimento web, trabalho com tecnologias como **Java, Spring Boot, JavaScript, React, HTML, CSS e Node.js**, abrangendo tanto a construção de interfaces quanto a implementação de regras de negócio, serviços e integração entre aplicações.

Também integro conhecimentos de **Inteligência Artificial e Ciência de Dados** ao meu desenvolvimento profissional. Tenho formação em Desenvolvimento de IA para Análise Preditiva, com conhecimentos em Python, análise exploratória de dados, preparação de datasets, algoritmos de Machine Learning, treinamento e avaliação de modelos preditivos e disponibilização de soluções por meio de APIs com FastAPI.

Busco desenvolver soluções tecnológicas que combinem boas práticas de Engenharia de Software, desenvolvimento web e inteligência orientada por dados, transformando necessidades reais em aplicações funcionais, eficientes e escaláveis.
