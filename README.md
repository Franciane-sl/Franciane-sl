## Projetos em Destaque

### DeliveryRisk AI — Sistema de Análise Preditiva de Atrasos em Entregas

Sistema de Machine Learning desenvolvido para identificar o risco de atraso em entregas de pedidos de e-commerce, utilizando dados históricos do mercado brasileiro.

O projeto implementa um fluxo completo de Ciência de Dados e desenvolvimento de software, abrangendo análise exploratória, preparação e integração de dados, engenharia de atributos, treinamento e avaliação de modelos preditivos, disponibilização de previsões por API REST e interface web interativa.

**Principais implementações:**
- Análise e preparação de dados utilizando Pandas e NumPy.
- Treinamento e avaliação de modelos de Machine Learning com Scikit-learn.
- Implementação de pipeline preditivo com Random Forest.
- Desenvolvimento de API REST com FastAPI e Pydantic.
- Interface web interativa desenvolvida com Streamlit.
- Persistência do histórico de previsões com SQLite.
- Testes automatizados com Pytest.

**Tecnologias:** Python, Pandas, NumPy, Scikit-learn, FastAPI, Streamlit, SQLite, Pytest e Joblib.

**Repositório:** [Acessar DeliveryRisk AI](https://github.com/Franciane-sl/DeliveryRisk_AI)

### MNIST Classification — Classificação de Dígitos Manuscritos

Projeto de Machine Learning desenvolvido para classificação multiclasse de dígitos manuscritos utilizando o dataset MNIST. O trabalho contempla a construção de um pipeline completo de aprendizado de máquina, desde a análise exploratória e pré-processamento dos dados até o treinamento, comparação e avaliação de diferentes algoritmos de classificação.

Foram implementados e comparados três modelos: **K-Nearest Neighbors (KNN), Random Forest e Multi-Layer Perceptron (MLP)**, com experimentos de ajuste de hiperparâmetros, análise de métricas, matrizes de confusão e custo computacional.

O projeto também explora aspectos de robustez e generalização, incluindo experimentos com classes ocultadas (*Class Masking*), detecção de limitações em cenários fora da distribuição (*Out-of-Distribution — OOD*) e classificação de imagens manuscritas próprias.

**Principais implementações:**
- Análise exploratória e visualização de dados.
- Pré-processamento, normalização e divisão estratificada dos dados.
- Implementação e comparação de KNN, Random Forest e MLP.
- Ajuste de hiperparâmetros e avaliação com métricas de classificação.
- Análise de matrizes de confusão e custo computacional.
- Experimentos de Class Masking e generalização OOD.
- Testes com imagens manuscritas próprias.
- Organização modular do código e reprodutibilidade dos experimentos.

**Resultados:** KNN alcançou 97,21% de acurácia no conjunto de teste, sendo o melhor resultado preditivo entre os três modelos avaliados. Os experimentos adicionais evidenciaram limitações de generalização em dados diferentes dos utilizados no treinamento.

**Tecnologias:** Python, NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn, Pillow, Joblib e Jupyter Notebook.

**Repositório:** [Acessar MNIST Classification](https://github.com/Franciane-sl/MNIST_Classification)

### Predictive Maintenance — Manutenção Preditiva com Machine Learning

Projeto de Machine Learning desenvolvido para identificar e prever possíveis falhas em equipamentos industriais a partir de dados operacionais e informações de sensores.

O projeto implementa um pipeline de aprendizado de máquina que contempla análise exploratória, tratamento e preparação de dados, engenharia de atributos (*Feature Engineering*) e balanceamento de classes com SMOTE. Foram desenvolvidos e comparados diferentes algoritmos de classificação para identificar o modelo com melhor desempenho na previsão de falhas.

**Principais implementações:**
- Análise exploratória e tratamento de dados com Pandas e NumPy.
- Engenharia de atributos para criação de novas variáveis preditivas.
- Preparação e transformação de variáveis categóricas.
- Balanceamento de classes utilizando SMOTE.
- Normalização de dados com StandardScaler.
- Implementação e comparação dos algoritmos KNN e Árvore de Decisão.
- Ajuste de hiperparâmetros e análise de overfitting.
- Avaliação de desempenho e prevenção de Data Leakage.
- Persistência do modelo treinado com Joblib.

**Resultados:** a Árvore de Decisão apresentou o melhor desempenho nos experimentos, alcançando **94,8% de acurácia** no conjunto de teste.

**Tecnologias:** Python, Pandas, NumPy, Scikit-learn, Imbalanced-learn, Matplotlib, Seaborn e Joblib.

**Repositório:** [Acessar Predictive Maintenance](https://github.com/Franciane-sl/Predictive_maintenance)
